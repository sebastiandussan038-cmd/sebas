Diccionario de palabras de Software

Inglés - Español

  1. Software: Programas y aplicaciones de una computadora.
  2. Hardware: Partes físicas de una computadora.
  3. Application: Aplicación o programa que realiza una tarea.
  4. Program: Programa informático.
  5. Code: Código utilizado para crear un programa.
  6. Programming: Programación.
  7. Developer: Persona que desarrolla programas.
  8. User: Usuario que utiliza un programa.
  9. File: Archivo.
  10. Folder: Carpeta donde se guardan archivos.
  11. Database: Base de datos.
  12. Server: Computadora que proporciona información o servicios.
  13. Network: Red que conecta diferentes dispositivos.
  14. Browser: Navegador web.
  15. Website: Sitio web.
  16. Download: Descargar archivos o información.
  17. Upload: Subir archivos o información.
  18. Update: Actualizar un programa.
  19. Install: Instalar un programa.
  20. Delete: Eliminar.
  21. Save: Guardar.
  22. Bug: Error o fallo de un programa.
  23. Password: Contraseña.
  24. Login: Inicio de sesión.
  25. Database: Base de datos.
  26. Function: Función que realiza una tarea.
  27. Variable: Espacio donde se almacena un dato.
  28. Data: Datos o información.
  29. Algorithm: Pasos para resolver un problema.
  30. Backup: Copia de seguridad.
  31. Write: Sirve para escribir o guardar informacion en un archivo.
  32. Once: Indica que una accion se realiza una sola vez.
  33. Run: Sirve para ejecutar un programa o código.
  34. Anywhere: Indica que algo puede hacerse o funcionar en cualquier lugar.
